# Tai lieu on tap nhanh

## Cau 1 — So nguyen va ham

- %: phep chia lay du, dung de lay chu so cuoi.
- //: phep chia lay phan nguyen, dung de bo chu so cuoi.
- while: lap den khi so khong con chu so.
- return: tra ket qua tu ham.
- Cong thuc: S = 1/2 + 1/4 + ... + 1/(2*n).

## Cau 2 — Chuoi

- isupper(): kiem tra ky tu viet hoa.
- isdigit(): kiem tra ky tu co phai chu so hay khong.
- s[::-1]: tao chuoi dao nguoc.
- So sanh s == s[::-1] de kiem tra chuoi doi xung.

## Cau 3 — Danh sach

- []: tao danh sach rong.
- append(x): them phan tu vao cuoi danh sach.
- break: ket thuc vong lap.
- Dieu kien so duong chan: x > 0 and x % 2 == 0.

## Cau 4 — Tu dien

- {}: tao tu dien rong.
- Key la ma so sach.
- Value luu thong tin sach.
- ma_so in tu_dien: kiem tra key.
- del tu_dien[ma_so]: xoa sach theo key.

## Cau 5 — Huong doi tuong

- class: khai bao lop.
- __init__(): phuong thuc khoi tao doi tuong.
- self: tham chieu den doi tuong hien tai.
- Thuoc tinh luu du lieu; phuong thuc thuc hien hanh dong.
